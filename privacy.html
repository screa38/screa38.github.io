Datenschutzerklärung – Hermes Workspace

Stand: 19.10.2026

Verantwortlicher

Sebastian Elsen (Betreiber von Hermes Workspace). Kontakt über die im Google-Zustimmungsbildschirm angegebene Support-Adresse.

Welche Daten verarbeitet werden

  • Google Kalender: Lesen von Terminen und Anlegen eigener Hermes-Einträge (Fristen, Erinnerungen).
  • Gmail: Lesen von Nachrichten-Metadaten, um Vorgänge und versendete Schreiben zu erkennen. Hermes versendet keine E-Mails ohne ausdrückliche Freigabe des Betreibers.
  • Google Drive: Ablage und Lesen von Dokumenten in den dafür angelegten Ordnern.

Zweck

Die Daten werden ausschließlich genutzt, um die eigenen Termine, Fristen, Aufgaben und Dokumente des Betreibers zu organisieren.

Weitergabe

Es erfolgt keine Weitergabe oder Verkauf an Dritte. Die Verarbeitung findet auf einem vom Betreiber kontrollierten Server statt.

Speicherdauer und Widerruf

Zugriffe können jederzeit unter myaccount.google.com/permissions widerrufen werden. Daten werden gelöscht, sobald sie für den Zweck nicht mehr benötigt werden.

Google API Services User Data Policy

Die Nutzung von Daten aus Google-APIs entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).
